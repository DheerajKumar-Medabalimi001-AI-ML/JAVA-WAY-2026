## 🌟 About This Repository

**JAVA-WAY-2026** is a collection of small Java programs created to practice core programming concepts step by step. The examples focus on clear logic, experimentation, and building confidence with Java fundamentals.

```text
Write it  →  Compile it  →  Run it  →  Understand it  →  Improve it
```

## 🚀 Getting Started

### Prerequisites

- [Java JDK](https://www.oracle.com/java/technologies/downloads/) 8 or later
- A terminal or IDE such as VS Code, IntelliJ IDEA, or Eclipse

Check your installation:

```bash
java -version
javac -version
```

### Run a Program

Clone the repository:

```bash
git clone https://github.com/DheerajKumar-Medabalimi001-AI-ML/JAVA-WAY-2026.git
cd JAVA-WAY-2026
```

Compile and run any Java file:

```bash
javac Hello.java
java Hello
```

Example for a program with another filename:

```bash
javac movieticket.java
java movieticket
```

> Make sure the `public class` name matches the `.java` filename.
